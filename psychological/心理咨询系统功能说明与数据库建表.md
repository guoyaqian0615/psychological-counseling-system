### 数据表

### 1. user（用户表 → 放所有人的账号）

放：学生、初访员、咨询师、心理助理、管理员

记录所有人的账号、密码、姓名、角色。

```
id          编号
username    账号（学号/工号）
password    密码
name        姓名
gender      性别
phone       电话
department  院系
role        角色（student/visitor/assistant/counselor/admin）
```

------

## 2. time_config（时间配置表 → 系统全局时间）

放：咨询时长、间隔时间

所有咨询统一 30 分钟，两场咨询之间留缓冲时间。

```
id              编号
single_duration 单次咨询时长（分钟）
interval_minute 咨询间隔时间
```

------

## 3. duty（值班表 → 老师什么时候有空）

放：哪个老师、哪天值班、几点到几点

老师不是全天在岗，要登记「哪天、几点上班」，学生只能约在岗时间

```
id          编号
user_id     老师ID
duty_date   值班日期
start_time  开始时间
end_time    结束时间
status      是否可用
```

------

## 4. first_visit（初访预约表 → 学生预约记录）

放：学生提交的所有初访申请

学生填信息、提交预约，管理员要查看、审核，还要标记是否紧急。



```
id                编号
student_id        学生ID
student_name      学生姓名
apply_time        申请时间
questionnaire_score 问卷分数
status            状态（待审核/已通过/已拒绝/已完成）
visitor_id        初访员ID
visit_date        初访日期
visit_time        初访时间段
location          地点
is_emergency      是否紧急
is_alert boolean  是否红色报警
```

------

## 5. first_visit_result（初访结果表 → 初访员填的评估）

放：初访后的结论

初访结束后，必须记录学生危机等级、问题类型、最终结论（要不要继续咨询）

```
id                编号
first_visit_id    对应哪条预约
crisis_level      危机等级
problem_type      问题类型
conclusion        结论（无需咨询/安排咨询/转介）
```

------

## 6. counseling（正式咨询表 → 心理助理排的咨询）

放：正式咨询的整体安排

确定正式咨询的老师、时间、地点，并且默认连续锁定 8 周时段。

```
id                编号
student_id        学生ID
student_name      学生姓名
counselor_id      咨询师ID
counselor_name    咨询师姓名
total_weeks       总周数（默认8）
start_date        开始日期
counseling_time   咨询时间段
location          地点
status            状态（进行中/已结案/已脱落）
```

------

## 7. counseling_record（咨询记录表 → 咨询师每次填）

放：每一次咨询的情况

一共 8 次咨询，每次都要记：正常到场、请假、旷约、结案等。

```
id                编号
counseling_id     对应正式咨询ID
times             第几次咨询
status            状态（完成/旷约/请假/脱落/结案）
record            备注
```

------

## 8. closing_report（结案报告表 → 咨询结束填写）

放：最终结案存档信息

咨询收尾，填写固定格式报告，包含学生信息、咨询次数等，还要打印。

```
id                编号
counseling_id     对应咨询
student_id        学生ID
student_name      学生姓名
gender            性别
department        院系
phone             电话
problem_type      问题类型
total_times       总咨询次数
counselor_id      咨询师ID         
counselor_name    咨询师姓名       
start_date        咨询开始日期     
end_date          咨询结束日期     
conclusion        结案结论          ← 补充（对应Word报告打印需要）
create_time       报告生成时间      ← 补充
```

------

### 用 Spring Initializr 创建项目（最简单的方式）

#### 第一步：打开这个网址

👉 **[https://start.spring.io](https://start.spring.io/)**

#### 第二步：按下图配置

| 选项        | 选择                                 |
| ----------- | ------------------------------------ |
| Project     | Maven                                |
| Language    | Java                                 |
| Spring Boot | 3.3.x（选最新稳定版）                |
| Group       | com.school                           |
| Artifact    | psychology                           |
| Packaging   | Jar                                  |
| Java        | **21**（你装的是24，选21兼容性最好） |

#### 第三步：添加依赖，点右边 "ADD DEPENDENCIES"，搜索并添加这几个

- **Spring Web**（写接口用）
- **MyBatis-Plus**（操作数据库用）——搜 "mybatis"
- **MySQL Driver**（连MySQL用）
- **Lombok**（简化代码用）

#### 第四步：点 "GENERATE" 下载压缩包

#### 第五步：解压后用 IDEA 打开

- IDEA → Open → 选择解压的文件夹
- 等右下角 Maven 加载完成（可能要几分钟）
