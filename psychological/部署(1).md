### . 每个成员拿到后，在自己电脑做 3 件事

1. 装 MySQL记住你的密码
2. 新建数据库：**名字必须是 psychological**
3. 导入我发的 `psychological.sql` → 电脑上就有一模一样的表和数据了

## 一、先把本地环境准备好（每个人都要做）

1. 安装 **MySQL 8.0**（推荐）

2. 启动 MySQL

3. 本地 MySQL **root 密码设置

4. 新建数据库，名字必须是：

   psychological

   （小写）

   sql

   ```
   CREATE DATABASE psychological DEFAULT CHARSET=utf8mb4;
   ```

------

## 二、拿到代码后只改一处配置（非常关键）

文件路径：

plaintext

```
src/main/resources/application.properties
```

打开后找到这一行：

properties

```
spring.datasource.password
```

- **改成你自己的 MySQL 密码**

其他所有配置 **一律不要动**！

完整配置参考（你们发出去的版本）：

properties









```
server.port=8080

spring.datasource.url=jdbc:mysql://localhost:3306/psychological?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&characterEncoding=utf8
spring.datasource.username=root
spring.datasource.password=（改这里）
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

mybatis-plus.configuration.map-underscore-to-camel-case=true
mybatis-plus.type-aliases-package=net.suncaper.psychological.entity
```

------

## 三、用 IDEA 打开并启动项目

1. 用 IDEA 打开项目（Open → 选项目文件夹）
2. 等待右下角 **Maven 依赖下载完成**（第一次会慢一点）
3. 找到主启动类（带 `@SpringBootApplication` 的类）
4. 右键 → Run 启动
5. 控制台看到 **Started ...** 就成功了
